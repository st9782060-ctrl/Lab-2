## 1. Відповіді на ключові питання

1. **Як в мові програмування C++ позначити степінь?**  
   Для піднесення до степеня використовується стандартна функція `pow(x, y)` із заголовного файлу `<cmath>`, де `x` — основа, а `y` — показник степеня.

2. **Як в мові програмування C++ позначити $\sin$?**  
   Для обчислення синуса використовується стандартна функція `sin(x)` із бібліотеки `<cmath>` (аргумент `x` задається в радіанах).

3. **Як в мові програмування C++ позначити $\cos$?**  
   Для обчислення косинуса використовується стандартна функція `cos(x)` із бібліотеки `<cmath>` (аргумент `x` задається в радіанах).

4. **Як в мові програмування C++ позначається експонента?**  
   Для обчислення експоненти $e^x$ використовується стандартна функція `exp(x)` із бібліотеки `<cmath>`.
